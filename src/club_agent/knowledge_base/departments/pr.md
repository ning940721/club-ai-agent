# 公關與贊助

> 種子資料：一般性實務整理，請持續收錄社團實際成功的提案與合作經驗。

## 贊助提案信結構
- 主旨：清楚寫出「社團名稱＋活動名稱＋合作邀請」，例如「【攝影社成果展】合作贊助邀請」。
- 開頭一段說明社團與活動（時間、地點、預估參與人數、受眾輪廓）。
- 說明「為什麼找這家廠商」：受眾重疊、品牌調性相符，避免像群發信。
- 列出贊助方案分級（例如現金、物資、折價券），每一級對應的曝光回饋要具體（貼文露出次數、攤位、背板 logo 尺寸）。
- 結尾附上聯絡人、回覆期限，並附提案簡報或過往活動照片。

## 贊助回饋與露出
- 回饋要可量化：IG 貼文觸及、活動參與人數、問卷中對贊助商的印象。
- 活動結束一週內寄送結案報告與感謝信，有助於下次續約。

## 合作與危機溝通
- 跨社團合作先確認分工、經費分攤與名義（主辦／協辦），並留下書面紀錄。
- 出現狀況（延期、取消、合作方退出）時，先內部統一說法，再於官方帳號說明原因、影響與後續安排，避免各自回應。
