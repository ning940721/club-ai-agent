# 社課規劃

> 種子資料：一般性實務整理，請收錄社團歷屆課程規劃與學員回饋。

## 學期課程規劃
- 先定義學期目標（例如：讓初學者能獨立完成一件作品），再倒推每週課程。
- 課程難度循序漸進，期中安排一次成果分享或小型活動，維持參與動機。
- 避開期中考與期末考週，或改為輕鬆的交流型課程。

## 提升出席率
- 每堂課有明確的「帶得走的收穫」，並在宣傳時寫清楚。
- 加入實作與分組互動，減少單向講授。
- 課前一天提醒，課後分享講義或作品，讓缺席者也想回來。
- 定期收集簡短回饋（3 題以內），依回饋調整內容。

## 講師邀請
- 邀請信寫明課程主題、對象程度、時間長度、人數與講師費（或回饋方式）。
- 課前確認設備需求，課後寄送感謝信與學員回饋摘要。
