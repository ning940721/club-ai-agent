# 活動企劃與執行

> 種子資料：一般性實務整理，請收錄社團歷屆活動企劃書與檢討報告。

## 活動企劃書基本架構
- 活動名稱、目的與預期效益、時間地點、目標對象與人數。
- 活動流程（含時間表）、工作分組與負責人。
- 預算表、宣傳規劃、場地與器材需求。
- 風險評估與應變措施、活動後檢討方式。

## 工作分工與排班
- 依活動流程拆出工作項目，再分配到組別（場控、報到、器材、攝影、機動）。
- 當天排班保留機動人力，每個時段至少一位能做決定的總召或副總召在場。
- 活動前一週舉行行前會與彩排，確認每個人知道自己的時間與位置。

## 風險與應變
- 常見風險：天候、人數不足或過多、器材故障、講者或表演者臨時缺席、受傷。
- 每項風險寫出預防方式與發生時的處理流程，並準備急救包與緊急聯絡名單。

## 活動檢討
- 活動結束一週內召開檢討會，整理「做得好／待改進／下次建議」，存入交接資料。
