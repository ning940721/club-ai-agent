# 會議與文書

> 種子資料：一般性實務整理，可收錄社團歷屆會議紀錄範本。

## 有效率的議程
- 會前 1–2 天發出議程，每個議題標註「報告／討論／決議」與預估時間。
- 需要決議的議題附上選項與背景資料，讓與會者事先思考。
- 會議設主持人與計時人，超時的議題改為會後小組討論。

## 會議紀錄格式
- 基本資訊：會議名稱、日期時間、地點、出席與缺席名單、主持人、紀錄人。
- 每個議題記錄：討論重點、決議內容、待辦事項（負責人＋期限）。
- 會後 24 小時內發出紀錄，並在下次會議開頭追蹤上次待辦的進度。

## 交接文件
- 整理年度大事記、各部門 SOP、重要聯絡人、常用文件範本與歷屆檢討，集中存放於共用雲端資料夾。
