# 人資與社員經營

> 種子資料：一般性實務整理，請依社團規模與文化調整。

## 招生與面試
- 招生資訊寫清楚：社團在做什麼、時間投入、費用、新手是否可以參加。
- 需要面試的社團，事先準備固定題目與評分方式，面試後一週內通知結果。

## 提升參與與留任
- 新社員前三次參與最關鍵：安排學長姐帶領、小組互動、讓新人有具體任務。
- 定期舉辦非正式交流（聚餐、出遊），建立歸屬感。
- 追蹤出席狀況，連續缺席的社員主動關心原因。

## 幹部培訓與交接
- 交接手冊內容：職責說明、年度行事曆、各項 SOP、常用文件範本、重要聯絡人、帳號密碼移交方式、歷屆檢討。
- 交接期安排新舊幹部共同執行一次活動或會議，實際演練。
