# 場地與總務

> 種子資料：一般性實務整理。各校場地申請流程與時程不同，請替換為校內正式規定。

## 場地申請
- 大型活動場地通常需提早申請，熱門時段（期末成果展季）建議越早越好。
- 申請前確認：容納人數、是否可收費、音響燈光設備、可進場布置時間、復原與清潔規定。
- 取得場地確認後，再對外公布活動地點。

## 場地選擇與動線
- 依活動型態選擇：講座重視座位與投影、展覽重視動線與展板空間、表演重視舞台與音響。
- 規劃報到處、主要動線、緊急出口與休息區，避免人潮堵塞。

## 器材與物資管理
- 建立器材清單（名稱、數量、存放位置、狀態），借用時登記借用人與歸還日期。
- 活動前一週清點並測試器材，活動後清點歸還並記錄損壞。
