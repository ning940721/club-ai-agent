# 美宣與視覺設計

> 種子資料：一般性實務整理，請收錄社團自己的視覺規範與歷屆作品。

## 設計需求單
- 需求單內容：用途（IG 貼文、海報、布條）、尺寸、必要文字（活動名稱、時間地點、報名方式）、主視覺風格參考、截止日。
- 提出需求的部門提供完整文字，美宣負責排版，避免邊做邊改文字。
- 預留至少一輪修改時間；大型活動主視覺建議活動前 4–6 週完成。

## 視覺規範
- 主色 1–2 個、輔色 1–2 個，標註色碼。
- 指定標題與內文字體，注意字體授權是否可商用。
- 社團 logo 的使用方式（最小尺寸、留白、深淺底色版本）。

## 印刷與輸出
- 印刷檔使用 CMYK、300 dpi、加出血；IG 貼文使用 RGB，常用尺寸 1080×1350。
- 送印前列印小樣確認錯字與顏色。
