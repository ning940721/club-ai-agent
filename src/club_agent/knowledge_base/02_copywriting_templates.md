# 校園社群文案範本庫

> 種子資料：之後請持續收錄社團歷屆高互動貼文，並在標題標註互動率，作為 RAG 範例來源。

## 吸睛開頭（Hook）公式
- 痛點提問：「期中考完只想耍廢？這個週末給你一個更好的選擇👀」
- 數字清單：「3 個理由，讓你這學期一定要來一次社課」
- 反差懸念：「我們社團最常被問的問題，竟然不是『要不要會跳舞』」
- 限時稀缺：「只剩 20 個名額！報名倒數 48 小時⏰」
- 身分認同：「如果你也是那種看到海報就想拍照的人，這篇是寫給你的」

## 行動呼籲（CTA）寫法
- 一篇貼文只放一個主要 CTA，並寫明「做什麼 + 在哪裡 + 期限」：「👉 點主頁連結填表單，10/15（三）23:59 截止」
- 互動型 CTA：「留言 +1 抽 2 位送活動周邊」「標記一個會陪你來的朋友」
- 收藏型 CTA：「先收藏起來，報名那天才不會找不到」

## 活動宣傳貼文範本（輪播圖文）
1. 封面：活動名稱 + 一句主打價值 + 日期地點
2. 第 2 頁：你會得到什麼（3 點以內）
3. 第 3 頁：活動流程／亮點講者
4. 第 4 頁：報名方式、費用、名額
5. 末頁：CTA + 社團帳號 + 提醒收藏
內文：Hook → 活動價值 → 時間地點費用 → CTA → hashtag（5–10 個，混合大眾標籤與社團專屬標籤）

## 社團招生貼文範本
- 以「一位社員的一天」或「加入前 vs 加入後」的故事切入，比條列社團介紹更有代入感。
- 必備資訊：社課時間地點、是否需要經驗、費用、第一次體驗方式（如免費體驗社課）。

## 活動後回顧貼文
- 使用照片輪播與「數字回顧」（參與人數、滿意度），並感謝參與者與贊助商，為下次活動累積信任感。
- 標記參與者與合作單位，可觸及其追蹤者。

## Reels 腳本結構
- 0–3 秒：畫面衝擊或問題字卡（決定是否滑走）
- 3–15 秒：重點內容快剪，搭配字幕
- 最後 3 秒：CTA 字卡（「報名連結在主頁」）
- 長度 15–30 秒，使用當下熱門音樂可增加推播機會。
