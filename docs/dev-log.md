# 開發日誌

依企劃書「過程記錄方式」，記錄框架擴充、提示詞調校歷程與實測數據。

## 2026-09-28｜v0.1.0 系統原型

**第一階段（需求盤點與模組架構設計）**
- 依企劃書確立本期聚焦「行銷宣傳與數據診斷」模組，其餘面向（公關、財務、組織、營運）以 persona 保留擴充介面。

**第二階段（Agent 顧問邏輯與提示詞建置）**
- 建立三層 Agent：數據診斷 → 文案與策略 → 經營審查，未通過審查自動退回修訂（預設最多 3 輪）。
- 社群數據先由程式統計，再交由 Agent 解讀，以降低數字幻覺。
- 建立 RAG 知識庫種子資料：社群演算法規律、文案範本、宣傳時程範本、校園宣傳注意事項。
- 審查評分表六項；通過門檻：平均 ≥ 4.0 且每項 ≥ 3。
- 建立評鑑工具：時間節省率紀錄、導入前後成效比較。

**待辦**
- [ ] 蒐集實際社團近三個月 IG/FB 洞察數據，取代範例資料
- [ ] 收錄社團歷屆高互動貼文到知識庫
- [ ] 向課外活動相關單位確認正式宣傳規定，更新 `04_campus_promotion_guidelines.md`
- [ ] 進行情境 A、B 實測，記錄時間節省率與幹部評分

## 2026-09-28｜v0.2.0 改用 Gemini

- 新增 `GeminiLLM`，預設供應商改為 Google Gemini（`gemini-flash-latest`），Claude 保留為可選項。
- CLI 新增 `--provider`，並支援環境變數 `CLUB_AGENT_PROVIDER`、`CLUB_AGENT_MODEL`。

## 2026-09-29｜v0.3.0 網頁版

- 新增 Streamlit 網頁介面（`app.py`）：社團資料、數據診斷、活動宣傳企劃、使用說明與 CSV 範本下載。
- 金鑰與使用密碼放在 Streamlit Secrets；每位使用者有執行次數上限。
- 支援 Excel 在 Windows 另存的 Big5 編碼 CSV。
- 第一次以 Gemini 在本機成功跑完數據診斷。

## 2026-10-03｜v0.4.0 多社團與部門顧問（第一階段）

- 社團帳號登入：每個社團一組帳號，第一次建立時填社團資料；可設定邀請碼限制誰能建立帳號。
- 七個部門：行銷（正式版）、公關、財務、活動、場地、會議記錄、課程（測試版），各有顧問角色與種子知識庫。
- 部門顧問：選部門、輸入問題，產出行動步驟、文件模板、跨部門協作與注意事項。
- 社團動態：各部門紀錄全社團可見，顧問回答時會參考其他部門近況。
- 資料暫存在本機檔案；下一階段改接線上資料庫後再正式部署。
- 修正：Gemini 額度錯誤說明、已下架模型自動略過（v0.3.x）。

## 2026-10-04｜v0.5.0 部門設定、待辦、會議記錄、社長總覽（規劃第一批）

- 依需求擬定全社團平台規劃（docs/roadmap.md），新增建議部門：課程、總務、美宣、人資。
- 社團可勾選部門、改名、填寫部門細節（後台可隨時修改），AI 會參考部門細節。
- 待辦與進度：各部門記錄任務，社長總覽看全社團進度與逾期任務。
- 會議記錄：上傳會議記錄／LINE 對話 → 自動整理決議、待辦、重要日期；可直接提問並附原文出處；待辦一鍵加入任務。
- 社長：一鍵產生各部門進度彙整與下次會議議程。
- 帳號可變更密碼；網頁程式拆分為 web/ 下的多個頁面檔。

## 2026-10-06｜v0.9.0 財務部門：報帳流程、帳簿、預算與報表

- 報帳申請（所有部門）：取代 Google 表單；送出後取得報帳編號，可用編號查詢進度；自動檢查發票格式、重複發票、逾期申請。
- 財務管理（財務、社長）：以「財務密碼」上鎖（忘記時用社團帳密重設）。報帳審核（核准／退件，超過門檻需社長同意）→ 批次標記撥款；
  收支帳簿（手動收支＋已撥款報帳自動記為支出、目前餘額、待撥款提醒）；預算編列與執行率；月報／學期報表下載 Excel（摘要、收支明細、
  類別統計、預算執行、報帳明細）與 Word／PDF；AI 財務分析（FinanceAnalyst，不分享到社團動態）。
- 規範與設定：核准門檻、申請期限、期初餘額、學期期間；依設定產生「報帳與財務規範」建議文件；匯入 Google 表單回覆 CSV（自動猜欄位）。
- 限制：財務密碼是同一個社團帳號內的權限區隔，資料仍在同一台主機；個人帳號權限待第六批（線上資料庫）。

## 2026-10-06｜v0.8.0 議程對照與全社行事曆

- 議程對照：社長排好的會議時間表自動儲存（meeting_plans，以日期為 id）；會議記錄上傳時預設選擇日期最接近（前後 3 天）的議程，
  摘要同一次 AI 呼叫中逐一判斷議題「已決議／已討論、未決議／未討論」（MeetingSummary.agenda_review），不增加呼叫次數。
- 社長總覽：顯示上次會議未完成的議題，可一鍵加入下次議程；進度彙整的 AI 也會看到這些議題。重新開啟頁面會載入已排好的議程。
- 行事曆：新分頁，彙整自行新增的行程（events）、幹部會議議程、會議記錄中的重要日期與待辦期限；月曆檢視、部門篩選、匯出 .ics。
  社長總覽的「近期行程」改由行事曆提供。

## 2026-10-06｜v0.7.0 介面調整、Word／PDF 匯出、會議時間表、快速問答

- 版面：「社團設定」「使用說明」移到側邊欄下方，點選後主畫面顯示該頁（選部門或按「返回」回到部門功能）；分頁順序改為部門專屬功能 → 部門顧問 → 社團動態（v0.8.0 起行事曆放在最後）。
- 匯出：所有報告改為下載 Word（python-docx）或 PDF（fpdf2），檔案在按下按鈕時才產生。PDF 需要中文字型：Windows 用微軟正黑體，Streamlit Cloud 以 packages.txt 安裝 fonts-noto-cjk。
- 社長：可設定會議日期、開始時間、時長與地點（時間、時長、地點會記住）；AI 議程分鐘數依會議時長分配；新增可編輯的會議時間表（自動排出每個議題的時段、超時提醒），也可以不用 AI 直接套用基本議程。
- 分享：每個 AI 功能都可以選擇「完成後分享到社團動態」；關閉時結果只有自己看得到，之後仍可按「分享到社團動態」。
- 快速問答：部門顧問新增「快速問答」，從會議記錄、社團動態與待辦找答案並附出處（ClubQA）。
- 速度：問答類改用最低思考程度（minimal）；很長的會議記錄分段後同時送出摘要。

## 2026-10-05｜v0.6.0 視覺改版與速度調整

- 視覺：移除所有表情符號，改用米白底色與深藍灰主色、Noto Sans TC 字體、較小的標題與「測試版」標籤；隱藏 Streamlit 開發選單；登入頁置中。
